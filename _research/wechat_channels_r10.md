# 税务公众号采集通道调研（Round 10，2026-10-11）

> 结论先行：**没有"免登录、全量历史、无人值守"三全通道**。可行的组合是：
> ①官网优先（已验证）→ ②wechatDownload MCP 拿整号历史（半人工：PC 微信取 key）→ ③wechat2rss 私有部署做长期增量 RSS（150 元/年+1 个微信号）。
> RSSHub 公共实例微信路由、feeddd、wewe-rss（已归档）、wechat-article-exporter 均已死，勿再投入。

---

## 一、本机实测证据（curl / GitHub API，2026-10-11）

### 1. wechat2rss 公共实例（wechat2rss.xlab.app）——实例活着，但免费列表无税务号

| 测试 | 结果 |
|---|---|
| `GET /` | HTTP 200（0.9s） |
| `GET /list/all` | HTTP 200，解析出 57 个免费公众号 feed |
| **免费号构成** | **全部为网络安全类**（吾爱破解/看雪/腾讯玄武/长亭…），**0 个税务号** |
| `GET /feed/d2b0dc03….xml`（全频带阻塞干扰） | HTTP 200，最新条目 **2026-09-30**（12 天前）|
| `GET /feed/7fc9f534….xml`（安全客） | HTTP 200，最新条目 **2026-10-10**（昨天）→ **实例实时更新中** |
| `GET /feed/5b925323….xml`（思想花火） | HTTP 200，537KB 全文，但最新条目 2025-10-09（该号本身停更，非实例问题） |
| `GET /add/test`（无 token 加号） | 404 —— 官方文档明确 `/add` 需 `k` 参数（RSS_TOKEN 鉴权），公共实例不开放随意加号 |

官方 QA 关键事实：只收录**群发**消息（每号每天最多 1 次）；每号每天检查 1–2 次（时延 0–24h，均值约 6h）；只抓**最新 20 篇**；触发微信风控后等待翻倍（15min 起、上限 6h）。
私有部署：**15 元/月 / 150 元/年**（仅软件授权，自部署）；需**自有微信账号**——1 个微信号可支撑 400+ 公众号。

### 2. RSSHub 微信路由——公共实例全灭

| 测试 | 结果 |
|---|---|
| `GET rsshub.app/wechat/ceobec/…` | **HTTP 000（连接超时 21s）** |
| `GET rsshub.app/wechat/mp/msgalbum/…` | **HTTP 000（连接超时 21s）** |
| `GET rsshub.rssforever.com/wechat/ceobec/…` | **HTTP 503**（实例活、路由挂） |

社区佐证：GitHub issue #15874「微信公众号无法抓取」；2025 年 V2EX 实测"rsshub 上几种方案都用不了"。自建也无法绕过（路由依赖的搜狗/传神接口本身被封）。

### 3. feeddd.org——已死 3 年

GitHub `feeddd/feeds`（2093 星）：**最后提交 2023-07-05**。众包真人采集模式随贡献者流失而停摆。

### 4. qiye45/wechatDownload（9.7k★）——活跃，4.4 起**支持 MCP/Skill 调用**，但 4.7 版曾被标"已失效"

| 项目事实 | 值 |
|---|---|
| stars / 最后 push | 9728 / **2026-10-07**（活跃） |
| 最新版 | 4.7（2026-08-16），release 名标注「(已失效)」——该轮接口被微信打断的痕迹 |
| 4.4（2026-04-05） | **新增 MCP 和 Skill 调用**：下载文章/合集、获取公众号 ID、批量下载、导出数据 |
| 4.6（2026-06-21） | 修复"获取不到密钥"；MCP 支持监听 0.0.0.0（**WSL/远程可调**） |
| 2026-09 issues | 「获取密钥后下载不了」「现在还能使用吗」等均已 closed；2026-10-06 仍有功能请求 issue → 当前可用 |
| key 获取 | **必须 PC 微信客户端内打开文章链接**（GUI 操作+手机确认），无法纯无人值守；key 有有效期，需定期人工 |
| 形态 | Electron GUI（Win/Mac）+ 网页版 changfengbox.top/wechat + MCP server |

意义：这是**唯一能拿整号全量历史文章**且**Agent 可驱动（MCP）**的方案；人工仅参与"取 key"一步。

### 5. rachelos/we-mp-rss（4.9k★，wewe-rss 继任者）——自建可用，但增量模式受限

- cooderl/wewe-rss（9650★）**已于 2026-03-20 前 archived**；社区主力迁到 rachelos/we-mp-rss（4881★，pushed 2026-10-10，Docker 一键部署）。
- 主模式走公众号后台接口，需**扫码授权**（TOKEN_EXPIRE 4320 分钟≈3 天，带过期提醒/webhook 通知）。
- 备用模式 `weread_mp`（公众号后台接口不可用时）：直接请求 weread.qq.com，但新版微信读书 `/api/mp/cover` **每次只返回最新 1 篇**（cover 增量采集），**无历史回溯**；需手工复制 weread Cookie（wr_vid/wr_skey/wr_rt）；-2041/-2012/-2010 为认证/风控错误。
- 结论：适合"长期增量 RSS"，不适合建库初期的一次性全量收割。

### 6. Mp2RSS（areyoubugcoder，34★，pushed 2026-10-11）——设计最贴合 Agent，但服务当前不可达

- 免微信账号（GitHub/Google OAuth）、贴一篇文章 URL 即订阅整号、**2–3 小时时延**、Markdown 正文、RSS/JSON API/CLI/**Claude Skill** 多形态交付、50/99/399 元每 30 天三档。
- 首次订阅**不回溯历史**。
- **实测（2026-10-11）：主站 mp2rss.bugcode.dev 两个网络（本机 curl + WebFetch）均 ECONNRESET，无法访问**（DNS 正常指向 Cloudflare）。付费前必须先复测；小项目存续风险高（文档站活着，服务站挂）。

### 7. 搜狗微信 adapter（已有资产）

`work/taxcase/adapters/sd_sc_weixin.py`：3–5 次查询即 antispider，新会话+420s 冷却可恢复。round9 用它收明税 12 件（连续 3×420s 冷却仍被拦）。只适合零散增量/验证账号存在性。

### 8. 税屋 shui5.cn「公众号文章」频道——不存在

税屋首页 JS 混淆（反爬），搜索引擎确认其栏目为法规/政策聚合，**无公众号转载专栏**；且税屋本身定位是政策库而非案例评析源。不建议作为通道，其政策内容已有更权威来源（chinatax.gov.cn）。

## 四、推荐执行顺序

**第 1 步（零成本，立即）— 官网增量收割**
华税官网新文章 + ctaxnews.com.cn 税案栏目 + 威科/四大税务刊。沿用 round9 模式（`work/taxcase/adapters/`），delay≥1.2s。

**第 2 步（建库主力）— wechatDownload MCP 拿整号历史**
1. Win 机器装 PC 微信 + wechatDownload 4.6+，GUI 取 key（人工 1 分钟）；
2. MCP 监听 0.0.0.0，Agent 走 MCP 批量下载：明税、税海涛声、财税茶座、中汇信达（官网死的/无官网的优先）；
3. 输出 md 直接入 `lawlibrary/专题/税务案例/全国/实务课程与书籍/`；每号连抓勿超 3 页/次，留间隔，key 过期再人工续。
风险对冲：版本失效周期≈微信接口变更周期，每次跑前查 releases（4.7 型"已失效"会出现在 release 名里）。

**第 3 步（长期增量）— wechat2rss 私有部署（150 元/年）或 we-mp-rss（免费）**
部署到现有 VPS，挂 1 个专用微信号，订阅 20 个目标号 → RSS/JSON 每日拉取入增量管线。选型：要省心选 wechat2rss（风控退避成熟、2021 年运营至今）；要零成本且接受 3 天续扫一次选 we-mp-rss。

**第 4 步（观察）— Mp2RSS**
每周 curl 一次 mp2rss.bugcode.dev；恢复可用且试用正常 → 可替代第 3 步（免微信号、2–3h 时延、原生 API/CLI/Skill）。

**第 5 步（兜底）— 搜狗 adapter**
仅用于：新号发现、验证账号存在性、个别热点文补收。

**合规边界（沿用 R9）**：只收作者/机构主动公开发布的公众号文章；不碰付费墙、不碰读书非试读内容；单号请求限速、避免触发风控牵连账号；产出物标明来源与"作者主动公开"性质。
