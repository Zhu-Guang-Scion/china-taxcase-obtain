## 1. 交易所纪律处分/监管措施

**入口（实测 200 可达，均为 JS 渲染、无服务端表格）：**
- 深交所：`https://www.szse.cn/disclosure/supervision/measure/decision/index.html`（纪律处分决定）、`measure/index.html` 下设处分/措施/公开认定分栏；问询函件在 `disclosure/supervision/inquire/index.html`
- 上交所：`http://www.sse.com.cn/disclosure/credibility/supervision/measures/`（纪律处分与监管措施合一页）；发行环节监管措施另在 `/regulation/listing/measures/`
- 制度依据：《深交所自律监管措施和纪律处分实施办法》（2025 年 5 月新版）、《上交所纪律处分和监管措施实施办法》（2026 年修订）

**量级（公开数据）：**
- 深交所 2023 年全年作出纪律处分决定书 **179 份**（处分上市公司 93 家次）
- 2024 年沪深北三所合计采取各类监管措施 **1,210 份**（新浪财经统计，含监管函/工作函）
- 上海重立律师事务所统计 2025 年度：深 48 / 沪 116 / 北 13 份（口径可能仅限部分类型，供参考）
- 公司侧镜像公告在巨潮有量级：标题级"监管函"9,352 条、"关注函"11,360 条（含沪深全历史）

**涉税相关度：粗估 <5%。** 处分主因是信披违规、资金占用、违规担保、减持违规、财务造假；涉税形态主要是（a）重大税务处罚未披露、（b）涉税财务造假（虚开牵连）、（c）因税务问题无法按期披露年报。按两所每年 200-300 份处分估算，涉税约 10-20 件/年，且**处分决定书标题不含"税"字**，无法关键词筛，需下载全部决定书做全文过滤。

**获取难度：中高。** 两所列表页均为前端 JS 拉数（深交所 HTML 内无 API 地址、上交所 query 老 sqlId 已废弃——R15 已证），需现场逆向分页接口；处分决定书 PDF 在两所官网。公司侧"收到监管函/纪律处分事先告知书"公告虽在巨潮可拉，但标题同样无涉税标识。

**建议：不专门收。** 产出比低（全年涉税增量约一二十件且需全量 PDF 全文过滤），且已入库 329 件公告正文里常自带"同时收到深交所监管函"等表述，个案交叉引用即可。

## 2. 年报/半年报问询函

**入口：**
- 交易所侧：上交所官网"监管问询"栏目（如"关于对 XX 公司 2025 年年报有关事项的问询函"，按公司/日期查）；深交所 `disclosure/supervision/inquire/`（问询函件）。两页均 JS 渲染。
- **公司侧（推荐）：问询函与回复是公司公告，全量在巨潮**——R15 同一接口直接可用，无需碰交易所页面。

**量级（实测+公开数据）：**
- 巨潮标题级命中：**年报问询函 20,557 条**、半年报问询函 1,085 条（含问询函+回复+延期回复等全历史）
- 2025 年报季（截至 2026-08-26）沪深北三所向 **446 家**公司下发年报问询函（上年同期 380 家，+17.37%）；2023 年报约 440 家——每年稳定 380-450 家
- 集中在每年 4-6 月（年报披露后）

**涉税相关度：高但深藏。** 税务是问询高频方向（收入确认与纳税口径、关联交易定价/转移定价、税收优惠可持续性、补税对业绩影响、税务稽查进展）。但实测标题级双关键词"问询函 税务"**全库仅 1 条**（复旦复华子公司补税案的会计师专项回复，2024），即税务内容几乎全部在回复正文里，标题筛不出来。

**获取难度：中。** 列表免费好拉（巨潮翻页规则已知）；难点在涉税筛选需下载回复 PDF 做全文过滤（每份回复几十至几百页，2 万份全量处理成本高）。

**建议：选择性收。** 方案：以已入库 329 件的公司名单为种子，反查这些公司收到的年报/半年报问询函及回复（公司维度小规模、命中率天然高——补税公司几乎必被问询），作为既有案例的"交易所质证"附件；全量收不划算。

## 3. IPO/再融资审核问询

**入口（实测可达）：**
- 上交所：`https://www.sse.com.cn/ipo/home/`（IPO 信息专区，含审核项目动态）+ `https://www.sse.com.cn/listing/disclosure/ipo/`（发行上市披露）；再融资在 `/listing/renewal/ipo/`
- 深交所：`https://www.szse.cn/listing/projectdynamic/ipo/`（IPO 审核动态，按受理/问询/上会/注册/终止分阶段）+ `https://www.szse.cn/listing/disclosure/ipo/index.html`（披露文件，**可按"问询与回复"披露类型筛**）+ 详情页 `www.listing.szse.cn/projectdynamic/ipo/detail/index.html?id=xxx`；再融资在 `listing/disclosure/refinance/`

**量级：** 2026-09 北交所排队 223 家已超沪深总和；2025-07 全 A 在审约 305 家；2023-11 高峰 728 家。每个项目 1-3 轮问询回复，每份回复数百页（一问一答全套）。

**涉税相关度：形式高、实质不符。** 每份问询回复都有标准税务章节（税收优惠占比、关联交易定价、历史沿革中的税务合规、补税风险），但这是**无违法结论的合规披露**，不是"违法事实+处罚结果"的税案；且只能按项目检索，无税务关键词筛选。

**获取难度：高。** 审核网站 JS 重、按项目逐个下载、PDF 巨大（单份数百页，抽税段落需全文处理）。

**建议：不收。** 与案例库定位（查处类案例）不符；若未来扩"税务合规披露知识库"（拟 IPO 企业税务风险点）再立项。

## 4. 北交所（巨潮同源实测）

**方法：** 巨潮 `POST /new/fulltextSearch/full`，`type:"shj"` + `isfulltext:false`，6 个关键词全量翻页（pageNum），按 secCode 前缀分类（920=北交所新码；83/87/88=北交所或新三板；4x=新三板/老三板）。

**实测结果：**
- `税务行政处罚决定书` 109 条、`税务处罚` 137 条、`税务处理决定书` 95 条、`税务事项通知书` 18 条、`补缴税款` 31 条、`税收保全` 4 条
- 去重后 250 条中 **920 前缀（北交所上市公司）= 0 条**
- 北交所现有上市公司约 260 家，整体上市时间短、规模小且偏"专精特新"，重大税务处罚披露极少

**结论：北交所单独路径价值≈0。** 其公告与新三板同在 `type:"shj"` 桶里，合并处理即可，无需独立通道。

## 5. 新三板/股转系统挂牌公司（同上实测，最高性价比增量）

**实测总量：6 关键词去重 250 条 / 约 155 家挂牌主体**：
- 8 开头（83/87/88）210 条 / 141 家；4 开头 20 条 / 14 家
- 另混入 20 条沪深**退市公司**公告（深大通、退市博元、凯马B5 等——退市后公告挂退市板块进 shj 桶），入库时按前缀剔除或并入退市专题
- ST 挂牌公司 27 条

**年份分布（仅三板）：** 2015:7 / 2016:22 / **2017:59 / 2018:47**（新三板扩容+信披严管高峰）/ 2019-2022:12-17 / 2023:15 / 2024:12 / 2025:6——**历史存量型信源**，新案供给不如沪深，但 2016-2018 深槽正是沪深公告里较薄的年代。

**形态：** 样本标题均为"[临时公告]XX公司:关于收到《税务处理决定书》…"，与沪深同形态（违法事实+金额+决定文书），PDF 直链规则与 R15 完全一致（static.cninfo.com.cn + adjunctUrl，无鉴权无限流）。

**获取难度：极低。** R15 adapter 改两处即复用：请求加 `type:"shj"`，入库前缀过滤改收 4/8/920。标题剥 `<em>`、毫秒时间戳等坑均已趟过。

**建议：收。** 预计净增 220-230 件（剔 20 条沪深退市重复），是本轮所有路径里唯一"低投入、确定增量"的，优先执行。注意：三板公司质量参差，门禁词表沿用 exchange-disclosure 分支应可复用；目录建议顶层设"股转系统/挂牌公司税务披露"（与两所并列，原文来源仍记巨潮）。

**补充：** 股转官网 `www.neeq.com.cn` 信息披露与自律监管（挂牌公司未披露税务处罚会被股转出具监管措施）为独立入口，但 SPA 架构、巨潮已覆盖公告本体，不必碰。

## 6. 上交所债券持有人披露（非上市公司发债主体）

- **上证债券信息网 `https://bond.sse.com.cn/`** 实测 200 可达，UI 带 keyword 检索（`/disclosure/more/index.shtml?keyword=…`），但结果 JS 渲染，本轮未逆向其查询 API，无法给出标题级命中量
- 深市债券走巨潮，但 6 关键词扫描中未出现任何债券代码命中——发债主体税案标题级量级存疑（发债城投/产业主体税案相对少，且公告标题常用"重大事项"不带"税"字）
- **获取难度：高**——沪市债券公告不在巨潮（巨潮是深所背景），需单独逆向 bond API

**建议：暂不收。** 量级不明+成本高；若未来做"城投/非上市发债主体税案"专题再立项。

## 7. 其他发现

- **互动易（深交所，irm.cninfo.com.cn）**：搜索 API 免鉴权实测可用（POST /newircs/index/search）。税务相关问答量小：补缴税款 25 / 税务处罚 16 / 税务稽查 3 条。问答体非文书，不作案例源；可作为已入库公司的后续追踪线索（投资者常追问补税影响）。
- **上证 e互动（sns.sseinfo.com）**：页面可达，ajax 端点未对上（500），价值同上，不投入。
- **公告"其他"类里的税务自查报告**：R15 关键词集（补缴税款/税务事项通知书等）已覆盖，无需新通道。
- **北交所官网 bse.cn / 股转 neeq.com.cn**：均为 SPA+API，巨潮同源覆盖，不必直连。

## 合规说明

本轮仅评估公开网页与公开接口（巨潮/两所官网/互动易），请求带浏览器指纹属常规访问；未涉及、未建议任何绕过鉴权、破解验证码或伪造身份的手段。所有接口均为无登录公开数据。
