## 2. 信源详情

### 2.1 总局政策法规库 fgk.chinatax.gov.cn【P0，官方权威】

- **入口**：总局官网高级搜索表单 action 指向 `https://fgk.chinatax.gov.cn/zcfgk/c100028/zcwj.html`（政策导航页，客户端渲染）。
- **数据 API（实测 curl_cffi 直连 200，无验证码无墙）**：
  ```
  GET https://www.chinatax.gov.cn/search5/search/s?siteCode=bm29000002
      &searchWord={词}&type=&pageSize=20&pageNum={n}&orderBy=5
      &column=%E6%94%BF%E7%AD%96%E6%B3%95%E8%A7%84        # column=政策法规 限定库内
  返回 searchResultAll.searchTotal[] 每条含: title / url / govDoc.docNum(文号) /
        govDoc 发文机关 / cwrq 成文日期 / pubDate / label(税务规范性文件…) /
        effectLevel 时效性 facet
  分页: searchResultAll.total 为总数，pageNum 递增
  ```
- **实测计数（column=政策法规）**：批复 471 ｜ 国税函 333 ｜ 税总函 22 ｜ 税总发 67 ｜ 税函 3。全库（searchWord=国家税务总局）3,780 件。
  关键词有全文匹配噪音（引用国税函的公告也被计入），采集时以 `govDoc.docNum` 二次过滤文号前缀。
- **正文质量【实测】**（`fgk.chinatax.gov.cn/zcfgk/c100012/c5193678/content.html`《国家税务总局关于果啤征收消费税的批复》国税函〔2005〕333号）：
  > 你局《关于青岛啤酒汉中有限责任公司生产销售"汉斯果啤"有关消费税问题的请示》（陕国税发〔2004〕224号）收悉。经研究，批复如下：……果啤均属于啤酒，应按规定征收消费税。
  
  正文容器 `class="TextContentDuanLuo"` 段落；页头带 文号/成文日期/时效性（全文有效）/阅读量。**批复天然=问答型富文本（案情+口径）**。
- **覆盖年代**：实测最早见 国税函发〔1991〕1081号 —— 1991 年起。
- **建议提案答复栏**（chinatax.gov.cn 直属，非 fgk）：`/chinatax/n810214/c102374/c102387/index.html` 静态列表 20 条/页【实测 20 条直出】，人大建议 47 + 政协提案 39；答复全文含大量执法口径（如代扣代缴、限售股个税）。
- **与现有库关系**：flk 不收函【背景确认】+ lawlibrary/manifest.csv 实测 0 件函/0 件公告 → **零重叠**；fgk 其余 ~3,100 件公告/规章若未来扩法规库可直接复用同一 API。

### 2.2 税屋 shui5.cn 中央法规年份列【P0，主量源】

- **站点**：帝国CMS（robots.txt Disallow /d/ /e/class/ 等，article 页允许）。文章 URL `https://www.shui5.cn/article/{2hex}/{id}.html`，**无登录墙、无付费墙**【实测 8 篇正文直出】。
- **墙与过法【实测】**：首页起全站阿里云 WAF（`acw_sc__v2` JS 挑战 + ssxmod CDN cookie）。**playwright headless 一次过**（挑战自动执行，等 renderData textarea 消失即通行）；Node 离线执行挑战 JS 会死循环（反调试），别走离线解法。会话内可连续抓，配 2.5s+抖动。
- **栏目结构**：
  - 中央：`/article/1994NianShuiShouFaGui/ … 2026NianFaGui/`（1994-2026 按年，列 URL `/article/{slug}/{colid}_{page}.html`，14-40 页/年）
  - 地方：`/article/DiFangCaiShuiFaGui/` → 31 省子列（`GuangDongShengCaiShuiFaGu` 188 页、`ShangHaiShiCaiShuiFaGui` 99 页、`ZheJiangShengCaiShuiFaGui` 119 页【实测】）
  - 检索：无站内搜索（form 指向 zhannei.baidu.com 已死）、无 tag、无 sitemap → **只能年份/省份列分页枚举**（每页列表 ~30-40 条 + 固定侧栏 ~90 条需剔除）
- **正文质量【实测 8 篇】**：`div.arcContent`，1924/605/1877/**817(批复)**/981/502/2782/2237 汉字。批复样例（国税函[2009]779号 黑龙江垦区土地承包费批复）完整含：主送机关→请示文号→农场双层经营体制案情段→口径段（内链到企业所得税法条文）。
- **量估算（实测密度曲线插值）**：
  | 年份 | 1996 | 2001 | 2004 | 2009 | 2011 | 2014 | 2017 | 2020 | 2021-2026 |
  |---|---|---|---|---|---|---|---|---|---|
  | 函+发/年 | 374 | 374 | 826 | 576 | 105 | 176 | 81 | 68 | **≈0** |
  
  → 中央列 1994-2020 合计 **~9,900**（函+发混计），纯函（国税函/税总函/税总办函）≈60% → **~5,900**；标题含"批复" ≈15% → **~1,500**。
  **注意：2021 年起中央年份列几乎无新税总函**（总局近年函件基本不公开，公开走公告/12366）——"近三年批复增量"在中央层级结构性趋零，价值在历史存量与省局函。
- **合规**：所收为官方文件全文（著作权法第5条官方文件不适用）；**必须排除税屋原创栏**（实务解读 ShiWuJiDu/税务合规 ShuiWuChouHua/税务稽查 ShuiWuJiChaAnLi 等为站点原创/汇编作品）；单线程 2.5s+抖动，仅学习库用途，标转载来源。文章分页：存在 `$2.html` 后缀多页文（长法规），解析器需跟进。

## 3. 去重键设计

**主键：规范化文号（docno_key）**
```
原文号变体: 国税函〔2009〕779号 / 国税函[2009]779号 / 国税函(2009)779号
规范化:     去空格 → 括号〔[]()〕全删 → 全角数字/字母转半角 → 机关简称转小写拼音
            → "国税函2009.779" → key = gsh|2009|779
机关前缀映射: 国税函发/国税函→gsh, 税总函→szh, 税总办函→szbh, 税总发→szf,
              国税发→gsf, 财税→cs, 沪税函/沪国税函→sh.shh/sh.ghh, 粤税函→gd.yth …
```
- **fgk**：直接用 `govDoc.docNum`（权威、带全角〔〕）。
- **shui5**：从标题正则 `^(?P<org>[国税总财税沪粤浙苏京鲁…]{2,8}?(?:函|发|批))(?:〔|\[|\()?(?P<yr>\d{4})…?号` 抽取；抽取失败（~5%，如老文号/无号）回退 `title_norm + 成文日期` 复合键。
- **无文号类**（建议提案答复、部分问答式通知）：`title_norm + 成文日期`。
- **跨源去重**：fgk ∩ shui5 中央列预计重叠 ~70-80%（同批国税函）；以 fgk 版本为权威记录（保留双 URL），shui5 版本作 `alt_source` 合并。
- **与现有库**：lawlibrary 实测 0 函 0 公告（manifest 全扫）；12366 5,019 件为问答无文号——**均零冲突**，无需迁移比对（法规库 manifest 留作未来 fgk 公告类扩展时比对）。
- **采集内去重**：shui5 同文多页（$2.html）取同 id 合并；侧栏热文链接按 URL id 去重。

**质量门槛（沿用 v2 思路，批复类豁免事实具体性——批复天然含案情）**：
- 函/批复：全收（本身即口径答复）；仅剔除"印发名单/会议通知/内部管理"类（标题含 名单|会议|任免|值班|印章|着装）。
- 通知类（国税发/税总发）：仅收含口径段落者（正文匹配 `现将有关.{0,6}问题.{0,4}(通知|明确)如下|执行口径|比照` 且正文≥400 字），否则丢弃。
- 省份列：标题必须含"税"机关（省税务局/税函），剔省府/人社/医保函。
