# R11 LLM 语义甄别指南（子智能体必读）

## 判定维度与选项
每件三选一：
- **KEEP**：现行口径或内容与时间无关（历史事实本身有参考价值且依据未变）
- **TAG**：内容扎实但**依据已废止/全面修订**——保留，加「历史口径」标注（处置器自动插 front matter）
- **DEL**：清理。仅限以下明确证据之一：
  1. 机械宣传无实质：宣传月/税收宣传日活动稿、领导讲话/调研报道、工作成效总结、"某局开展XX活动"新闻、纯政策标题转载无任何解读、招聘/会议/培训通知
  2. 时效性死亡：内容完全依附已废止框架且无 enduring value（见时间线），换到今天会得出错误做法
  3. 非税务内容混入（错误收录）
- **拿不准 → KEEP 或 TAG，绝不 DEL**（保守原则；本库可承受少量噪音，不可承受误删）

## 判定流程（每件）
1. 读 excerpt（front matter 字段已单列）；excerpt 不足以判断时可 Read 原文（路径相对 lawlibrary/专题/税务案例/）
2. 实质性：是否含 具体案情/具体口径答复/操作路径/法条适用分析？纯宣传语汇（营造氛围/深入人心/成效显著/广泛开展）→ DEL 候选
3. 时效性：对照下方时间线，判断核心依据是否已被替换
4. 桶特例：
   - **E 裁判文书**：历史判例——默认 KEEP；核心法条已大改（如旧征管法/旧发票办法时代且争议点已消失）→ TAG；DEL 仅限非涉税/空文书
   - **A 批复函件**：总局 2018-2021 多批次集中废止了大批国税函（尤其税收优惠类/征管程序类）。优惠类老函（如"XX免征"）政策基本都换过→TAG 或 DEL；程序性/解释性老函若内容已无意义→DEL；仍被沿用的一般规范性答复→KEEP
   - **B 12366 老问答**：营业税时代问答（2016 前）且与增值税现制冲突→DEL；个税 2019 前的扣除/申报口径→TAG/DEL；纯 timeless（如发票基本常识）→KEEP
   - **C 媒体课程**：重点抓机械宣传；机构评析/案例解读→KEEP
   - **D 老案例**（<2018）：事实参考仍在→KEEP 或 TAG（依据大变时 TAG）

## 时效知识底座（重大变革时间线）
- 2016-05：营改增全面推开（营业税退出——此前营业税问答/函多数失效）
- 2018-2021：总局多批次废止国税发/国税函文件（税收优惠类几乎全换代）
- 2019-01：新个税法施行（专项附加扣除、综合所得——此前个税口径大改）
- 2020-2022：小规模纳税人减免系列多次调整；2022 增值税留抵退税制度化
- 2021-03：两办《关于进一步深化税收征管改革的意见》（金税四期/以数治税时代）
- 2023-07：发票管理办法修订（虚开等条款调整）
- 2024-12：增值税法通过（2026-01-01 施行，暂行条例时代进入尾声）
- 2026：全国税务行政处罚裁量基准（2026 年版）发布——各省旧裁量基准随之更新
- 刑法 205/201 等涉税罪名框架长期稳定（虚开/逃税判例 enduring）

## 输出格式
逐条写 verdicts JSONL（与批次号同名）：
{"path": "<原 path>", "verdict": "KEEP|TAG|DEL", "reason": "≤30字中文"}
- 不得漏条：批内每条 path 必须有 verdict；reason 必填
- 只写 verdicts 文件，不改库内任何文件
