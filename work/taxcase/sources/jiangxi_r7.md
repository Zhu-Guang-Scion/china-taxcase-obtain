# 第七轮：江西省（jiangxi.chinatax.gov.cn）——xxgk 处罚公示 xlsx 附件展开（2,003 件）

日期：2026-10-11 ｜ adapter：`work/taxcase/adapters/jx_xzcf_r7.py`（4 线程）｜ 断点：`progress/jx_xzcf_r7.jsonl`
入库：**2,003 件**（cap 触顶；`lawlibrary/专题/税务案例/江西省/行政处罚公示/<市>/`，11 市分区）
覆盖：**2025-07 → 2026-10**（量控 2,000 上限停扫；余 2023-10→2025-07 约 190 页未扫，复跑即续）

## 一、入口与机制（实测）

1. **无失信公布栏**：信息公开 col31013 树下无"重大税收违法失信"栏目（信用信息双公示
   area=XYXXSGS 树里只有 行政处罚信息公示 一个叶子）→ 直接走处罚公示（信源优先级 2）
2. **入口**：信息公开 > 信用信息双公示 col36187 > **行政处罚信息公示 col32618**
   （页面本身是空壳，数据由大汉 xxgk 动态模块填充）
3. **列表接口**（GET，无验证码、无反爬，curl_cffi chrome124 直连）：
   ```
   https://jiangxi.chinatax.gov.cn/module/xxgk/search.jsp
     ?infotypeId=&vc_title=&vc_number=&area=XZCFXXGS&divid=div1576&jdid=26&currpage={n}
   ```
   20 条/页，共 **6,111 条 / 306 页**（2019-07→2026-10）。
   行结构（属性挂在 <a> 上）：`syh='索引号' jg='机关' rq='日期' mc='标题'`
4. **详情页**：正文只有一行 .xlsx 附件链接
   `/module/download/downfile.jsp?classid=0&filename={md5}.xlsx`（无正文）
5. **xlsx = 数据本体**，两种表头布局：
   - A（稽查局版，19 列单行表头）：行政相对人代码(统一社会信用代码)/名称/决定书文号/
     案件名称/**处罚事由**/**处罚依据**/**处罚结果**/处罚机关/法定代表人姓名/处罚类别…
   - B（县区局版，36 列**两行合并表头**）：行政相对人名称/代码（子列 统一社会信用代码）/
     **违法行为类型**/**违法事实**/**处罚依据**/处罚类别/**处罚内容**/罚款金额（万元）/
     处罚决定日期/处罚机关（+机关代码列，注意区分）…
   - 解析按 alias 优先级映射（违法事实 > 违法行为类型；处罚内容 > 处罚结果），
     两版统一到同一 schema

## 二、抓取与门槛

- 翻页扫列表 → 标题尾"（无）/无/无数据"空批次直接跳过（wu）→ 逐条下详情取附件 URL →
  下载 xlsx → 行展开 → **facts 门槛（违法事实/事由 + 处罚内容/结果 汉字 ≥30，
  处罚依据法条不计入）** → 一行一案写 md
- FINAL：112 页 / 2,240 批次（2026-10→2025-07）/ 4,022 行 / **kept 2,003 / DEL 1,996**
  （DEL 主要是"违反税收管理"类目短语+罚款金额型行，事实叙述不足 30 字）
- facts 汉字分布：min 29 / p10 32 / 中位 46 / max 1,047；quality_prune.decide() 全 KEEP
- 富样本："永修本荣汽车销售中心虚开机动车销售统一发票100份，价税合计302.4万…"；
  "检查所属期间，逃避缴纳增值税9294.91元、企业所得税56359.23元…"（决定书级量化叙述）
- 4 线程并行后 ~7 分钟/10 页；单线程太慢（20 items × 2.5s/页 ≈ 50s/页）

## 三、坑

1. **selfUrl/列表 href 均为 http://**（https 站），下载请求统一走 https 即可
2. xlsx 的 Content-Type 是 text/html（服务端错标）——按 PK 魔数判断，勿信头
3. 少数批次是 .xls/损坏文件（16 个 fail 留档）；219 个 no-att 实为标题不带"无"的
   空批次（详情页无附件无正文）
4. 表头两版并存且列序不同——**必须按列名映射，不能按位置**；
   B 版"处罚机关统一社会信用代码"列易误映射到相对人代码（用 exclude 词排除）
5. 数值单元格空值会读出字符串 "nan"（282 个文件已批量清洗为"（未列）"）
6. 索引号 XZCFXXGS/{年}-{序号} 按年重排——不能当全局唯一键，用 详情 URL+行号
