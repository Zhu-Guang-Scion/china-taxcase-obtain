## 3. 坑（本轮新增，后人必读）

1. **search5 空响应节流**：开普云后端对连续 POST 偶发返回 HTTP 200 + total=0 + 空 docs
   （非报错、非翻到底——翻到底也是这个形态，两者不可区分）。首轮因此把 普法/警示/
   非居民/股权转让/社保费 等词整词漏扫。**对策：空响应按失败退避重试 4 次**
   （真零词如"税收筹划"每次多花 ~25s，可接受）；翻页结束与节流的区分只能靠重试后仍空
2. **search5 老文档 http:// scheme**：2023-2024 的详情 URL 索引为 `http://`，
   前缀检查（startswith https://…）会静默丢弃——必须先归一 scheme（实测 https 可访问老页）。
   本轮靠它补回 27+ 件 2023-2024 件
3. 广东站无 was5；gdtaxejs 频道 JSON 接口的 URL 相对路径基准是站点根（round1 已知，
   本轮 C2 复用）
4. 横琴 tzgg 的 .xls 附件是纳税人名单（名字+文书号），不是决定书全文——
   与东莞 docx 附件（决定书全文）形态不同，别按东莞经验去抓
5. hengqin.gov.cn 的站内检索托管在 search.gd.gov.cn（Vue SPA 无服务端渲染），
   curl 拿不到结果；该站文章 URL 无固定频道段（/content/post_NNN 直接 404），
   搜索引擎给的 post 链接可能已下架
6. 广州市司法局文书公开的 PDF 在 `https://sfj.gz.gov.cn/attachment/{n}/{n2}/{n3}/{postid}.pdf`，
   pymupdf 可直抽文本（本轮仅用于抽样验证复议方向，未入库）
7. **"典型案例"是高风险词**：search5 全文命中里混着省市场监管局铁拳/网络交易/广告
   违法/知识产权等非税典型案例（省站转载媒体报道），入库前必须按正文税词密度（<8 删）
   + 标题机构名双重过滤；"行政复议"词则直接捞到《行政复议法》《实施条例》法规全文
8. **宣传/培训类 PR 噪声大**（税宣月启动仪式、大讲堂、面对面、模拟法庭、游园、
   微课、APEC 助企…约占本轮标题命中 1/3）：自家 gate 的"风险路径"（动词+数字）
   拦不住，终审按"活动标题 + 无严格案例标记（某公司/案情/案例N/经查/决定书）→删"
   兜底；注意少数培训报道有实质干货（前海港澳金融企业合规培训含非居民协定风险点，
   留）
9. search5 的 total 每次查询会漂移（调解 209→223→256），索引在滚动更新，别拿 total
   对账
