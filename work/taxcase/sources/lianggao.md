抓取日期：2026-10-10。工具：`work/taxcase/taxcase_scrape.py` 的 `polite_get`（curl_cffi chrome124 指纹）+ 各站专用 adapter（`work/taxcase/adapters/`）。

## 一、最高人民检察院 www.spp.gov.cn

### 入口与机制
| 项 | 说明 |
|---|---|
| 典型案例专栏 | https://www.spp.gov.cn/spp/zgjdxal/index.shtml （TRS，分页 `index_2.shtml`…`index_12.shtml`，**无 index_1.shtml**；`createPageHTML('page_div',12,cur,'index','shtml',355)` 中 355=总条数、12=总页数）共354条典型案例合集 |
| 网上发布厅 | https://www.spp.gov.cn/spp/wsfbt/index.shtml （同构分页，34页共1059条，含2017年至今全部发布稿） |
| 指导性案例 | https://www.spp.gov.cn/spp/jczdal/index.shtml （按批列表，3页62条；**整批案例全文在一个批号页里**，如第四十六批=检例第183—186号全文） |
| 新闻发布会 | https://www.spp.gov.cn/spp/xwfbh/index.shtml （链接到各发布会专题页，非文章列表） |
| 站内搜索 | `/guestweb/s?siteCode=N000005434&searchWord=` —— **实测不按关键词过滤**（返回最新稿），无用 |

### 发现方式
全量枚举 zgjdxal(354) + wsfbt(1059) + jczdal(63批) → 标题含"税"过滤 → 命中7条；指导性案例按批全文抓取后按 税款/税收/发票/偷逃税/涉税 关键词复扫63批，确认仅第四十六批（检例第183号 成品油税收监管公益诉讼）为涉税批。

### 抓取结果（7件，adapter: `adapters/spp_cases.py`）
- 依法惩治涉税犯罪典型案例/ 2件：2024-08-23 骗取出口退税典型案例（最高检+公安部，4案全文）；2022-06-17 六部门公布5起骗取留抵退税案件
- 涉税检察公益诉讼/ 4件：2026-07 成品油涉税专项监督；2017年 山东聊城/湖北/安徽合肥 税务机关行政公益诉讼3件
- 指导性案例/ 1件：2023-08-03 第四十六批指导性案例（含检例第183号，偷逃税款·非标油大数据监督模型）

### 踩坑
1. **死链302到首页**：不存在的旧文（如第二十二批指导性案例 `t20201208_488360.shtml`，含检例第81号虚开增值税专用发票案）服务器302回67KB首页而非404，且该批在 jczdal 栏目中亦无存档 —— **检例第81号官网全文已失传**，adapter 以 title==首页判死链跳过。
2. 文章标题带 `_中华人民共和国最高人民检察院` 后缀需裁剪；页脚 `Copyrights©/备案序号/浏览器建议` 三段需裁剪。
3. 批号页里"（检例第18X号）"编号在 styled span 中，markdownify 转换后编号丢失（批首"检例第183—186号"仍在，可定位）。
4. wsfbt 分页 `createPageHTML` 末参数1000是封顶值，实际以"翻到空页/回首页"为准。

### 抓取结果（2件，adapter: `adapters/court_cases.py`）
- 2025-11-24 最高人民法院发布依法惩治危害税收征管犯罪典型案例（8案全文在发布稿内，/zixun/xiangqing/482251.html）
- 2025-11-25 八案释法：从涉税典型案例看人民法院如何精准惩治与预防税收犯罪（法院报解读，/zixun/xiangqing/482341.html）

### 踩坑
1. **2024-03-18"两高"涉税司法解释暨4个典型案例**：两高官网均无独立案例文章（court 搜索、104/39/77栏目、spp 全量枚举均未命中），仅国新办发布会页 http://www.scio.gov.cn/202403/t20240320_838682 有实录 —— 记录后跳过。
2. 公报 2022-2026 全部期次（60期POST扫描）标题无涉税案例条目（唯一命中为《增值税法》法条），公报维度放弃。
3. court 正文提取用通用回退链可用；标题需裁剪 ` - 中华人民共和国最高人民法院` 后缀。
4. 104专栏2025-11的涉税典型案例发布稿**不在**该专栏列表中（漏分类），靠站内搜索才找到 —— 两高站的栏目收录不全，搜索+栏目双通道都要走。

## 三、财政部 www.mof.gov.cn（会计信息质量检查公告）

### 入口与机制
| 项 | 说明 |
|---|---|
| 栏目 | 监督评价局子站 **jdjc.mof.gov.cn** 「工作通知及公告」/jianchagonggao/ |
| 分页 | `createPageHTML(11, 0, "index", "htm")` → index.htm + index_0.htm..index_10.htm，每页10条共108条（栏目全量，2013至今） |
| 详情URL | `/jianchagonggao/YYYYMM/tYYYYMMDD_NNNNNNN.htm` —— **必须带 YYYYMM 月份目录**；列表href是`./YYYYMM/...`相对路径，漏月份目录会得到"页面不存在或已删除"软404页（HTTP 200） |
| 主站 | www.mof.gov.cn 根路径是 UA 嗅探跳转壳，直接取 `/index.htm` |

### 抓取结果（46件，adapter: `adapters/mof_checks.py`）
- 会计信息质量检查公告 第十号~第三十四号（2013-2015）+ 第四十一号~第四十六号（2022-2024）
- 财会监督检查公告（更名延续）第四十七号~第五十二号（2025-2026）
- 年度新闻稿3件（2017/2018/医药企业，**内含编号公告全文**，恰好补齐缺失的35-40号区间）

2. 详情页无发布日期字段，日期取自URL的 tYYYYMMDD（2013年批量迁移的老文会统一显示迁移日）。
3. 公告正文常带 docx/xls 附件（处理情况表），已在 front matter 记附件链接（未下载，多为表格非正文）。

## 四、证监会 www.csrc.gov.cn（涉税行政处罚）

### 入口与机制
| 项 | 说明 |
|---|---|
| 行政处罚栏目页 | http://www.csrc.gov.cn/csrc/c101928/common_list.shtml |
| 列表JSON接口 | `/searchList/{channelid}?_isAgg=true&_isJson=true&_pageSize=20&_template=index&page=N`（来自 `/csrc/xhtml/js/render.js`）；行政处罚 channelid=`28de6b87eda140cb93de4dd10d11867d`，total=2036件，**pageSize服务端封顶20** |
| 详情 | `/csrc/c101928/cNNNNNN/content.shtml`，标题全部同名"中国证券监督管理委员会行政处罚决定书"，**文号〔20XX〕N号与当事人在正文内** |
| 站内搜索 | `/api/query?siteCode=bm2900xxgk&key=...` 实测忽略关键词（返回固定页），无用 |

### 筛选方式
近2年（2024-09-18~2026-09-01）全部240件决定书逐篇抓正文 → 税关键词（税款/税务/纳税/偷逃税/个人所得税/增值税/企业所得税/印花税/出口退税/欠税/骗税/虚开/税前列支/代扣代缴/股权转让）命中计数 → 阈值过滤 + 人工复核（涉税场景：股权转让偷逃税、并购重组税务违规等），量控50件。

### 抓取结果（4件）
近2年240件决定书全扫描：198件零命中、36件1-2次命中（多为罚没款计算式"不含增值税业务收入"或当事人名单里的"纳税申报表"，**均属附带提及**）、仅6件≥3次命中。逐篇人工核对关键词上下文后，**真正涉税场景仅4件**：
- 〔2025〕33号 北京兴华所（辅仁药业/开药集团虚构销售**未开增值税发票**、金税系统**纳税申报数据差异**未识别，17次命中）
- 〔2025〕27号 中审华所（**纳税申报材料/汇算清缴/小型微利企业所得税**核对审计失败，13次命中）
- 〔2025〕154号 江苏世纪同仁律所（华道生物**虚开发票**虚假销售 IPO 法律服务未勤勉尽责）
- 〔2025〕153号 公证天业所（同华道生物**虚开发票**案，年报审计）
- 落盘目录：lawlibrary/专题/税务案例/证监会/涉税行政处罚/

结论：证监会近2年**没有**"股权转让偷逃税/并购重组税务违规"类直接处罚（该类案件多由税务/公安管辖，证监会处罚事由集中在信披、操纵、内幕、审计失败）；涉税只以"虚开发票虚构销售""纳税申报数据审计不到位"形态出现。远低于50件量控上限，宁精勿滥。

### 踩坑
1. 决定书标题同名 → 文件名需从正文解析 文号（〔20XX〕N号）+当事人 构造。
2. 详情页顶部有"索引号/分类/发布机构"元数据表噪音，需裁剪；页面 `<title>` 是无关文案（"政府网站年度报表"），标题必须从正文取。
3. **"股权转让"关键词大量误报**（内幕交易/收购案的标的交易即股权转让，与税无关），"不含增值税""纳税申报表（证据清单）"亦为高频误报源 —— 必须看上下文不能只数命中。
4. 该 channel 仅**会机关**处罚决定；各证监局（派出机构）处罚在其地方栏目，未覆盖。
